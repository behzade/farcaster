License: `../../THIRD_PARTY_LICENSES/MATERIAL-ICON-THEME-MIT.txt` (MIT).

Files come from upstream `icons/<name>.svg`. Local names match upstream except:

| Local | Upstream |
| --- | --- |
| bash | console |
| config | settings |
| cplusplus | cpp |
| css3 | css |
| file | document |
| html5 | html |
| nixos | nix |
| vuejs | vue |

Keep SVGs unmodified and render as images to preserve their native colors.
Classification and embedding are in `src/app/ui/file_icons.rs`.
